## 目标和范围

用户要求开发 OpenWrt 版本并自动使用虚拟机验证，已确认目标架构为 x86_64。交付客户端，复用 `linux_webui` 和 vendored VNT 2.0 核心，不移植 Flutter GUI。版本沿用客户端 4.8.40，不触发 GitHub 发布。

## 实现

- `openwrt/build.sh`：WSL/Linux 静态 musl 构建、锁定依赖测试、ELF 动态加载器检查。
- `openwrt/package.py`：opkg IPK 与离线安装包、校验清单。
- `openwrt/files/`：procd 服务、随机令牌和持久化设备 ID 初始化。
- `openwrt/install.sh`、`uninstall.sh`：安装校验、保留业务配置、明确清理选项。
- `linux_webui`：OpenWrt feature、平台信息及页面部署说明、SIGTERM 释放网络实例。
- `openwrt/verify_vm.py`：真实官方 OpenWrt 镜像双 VM 数据面和生命周期验收。

正常重跑：

```sh
python3 VntcApp1.0/openwrt/verify_vm.py \
  --package VntcApp1.0/release/openwrt/vntc-openwrt_4.8.40-1_x86_64.ipk \
  --portable VntcApp1.0/release/openwrt/VNTC_OpenWrt_4.8.40_x86_64.tar.gz \
  --server-binary /opt/vnts2-wireguard-test/vnts2
```

执行前先停止保留的测试机，避免占用相同端口。默认测试结束会关闭本次进程；需要留机检查时添加 `--keep-running`。

## 验收边界

本轮实际验证 OpenWrt 24.10.5 x86_64 上的加密中继数据面。P2P 直连、真实路由器、特定 LAN 转发拓扑未验收。浏览器连接器在当前环境不可用，页面静态资源、鉴权、平台/版本信息及 JS 语法通过检查，不能代表浏览器视觉验收。
