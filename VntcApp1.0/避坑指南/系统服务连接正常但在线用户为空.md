# 系统服务连接正常但在线用户为空

## 表现

升级 Windows 安装版后显示已连接和虚拟 IP，但设备列表、聊天在线用户及远程协助目标为空。

## 根因

GUI 停止自行创建 VNT 核心后，旧 IPC 仅提供基础连接状态，业务页面仍遍历本地核心集合。仅给仪表盘增加“已连接”兜底无法恢复用户列表。

## 解决方法

服务提供不含配置秘密的网络快照，GUI 通过统一 `VntConnection` 接口读取本地核心或服务快照。轮询节点状态时保持连接对象身份；断线/切网时使旧引用失效。统计图也须经过相同接口，避免服务模式仍依赖本地 FFI 对象。更新安装时必须同时替换 GUI 编译产物和 `vnt_service.exe`。

生产环境只读检查使用 `dart run tool/vnt_service_status_probe.dart`，不要使用会替换网络配置的旧 IPC 探针。

## 验证

2026-11-17：Flutter 322 项、Rust 11 项和额外真实服务接口验收 1 项通过。实际安装目录同步后，IPC 从无快照/0 用户恢复为有快照/1 名在线用户/1 条路由。可视化验收被 Computer Use 的 app-server 启动错误阻断，未声称已完成。

另查到本机 UDP 61018 落入 Windows 保留端口段，产生聊天室 Presence 的 10013 错误；VNT 在线列表回退仍可用。该项与服务设备列表数据源缺失分开处理。
