# 仪表盘最小窗口尺寸优化

[CODEX_LONG_TASK_CONTINUE_V3]

日期：2026-11-05。

## 修改

- Windows 极简模式最小窗口由 610×450 改为 720×540 逻辑像素，为标题操作区、连接状态、三张统计卡片及底部组网/聊天/远程导航预留空间。
- 1080p、2K 默认窗口同步使用 720×540；4K 默认窗口保留 760×560。专业模式保留 800×600 下限。
- 入口共用 `DashboardWindowSizing.regularMinimumSize`，覆盖模式加载、模式切换及首次保存配置后的窗口调整。
- `window_manager` 在 `WM_GETMINMAXINFO` 中根据 DPI 换算拖拽下限。
